# Supplied research artifacts

These folders were copied from the supplied research exports with their original directory structure and file contents preserved.

- [FINAL RESULTS](FINAL%20RESULTS/): guide package, original data and reports, graph PNGs, reference tables, and the additional LSTM/GRU/Random Forest results package, including model files.
- [D05_FINAL_DATASET_EXPORT_v1](D05_FINAL_DATASET_EXPORT_v1/): main H14 dataset and splits, supporting campaign exports, audit reports, and final research reports.
- [SHA256SUMS.txt](SHA256SUMS.txt): checksums for all 174 supplied files, with paths relative to this directory.

The folders intentionally retain overlapping copies and their original ZIP archives so each supplied package stays complete. The additional model-results package is retained as supplied; its inclusion does not replace or revise the paper's reported H23 frozen-model evaluation. This upload does not change the website's displayed results.

Model binaries are supplied artifacts; no model files were executed or deserialized during this import.
