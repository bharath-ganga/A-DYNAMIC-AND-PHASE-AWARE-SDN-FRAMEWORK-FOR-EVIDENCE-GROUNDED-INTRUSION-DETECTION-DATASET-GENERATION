Mininet + Open vSwitch

Virtual hosts and switches form the isolated network testbed. The diagram uses a small teaching topology, not an exact experimental deployment.

Ryu + OpenFlow 1.3

The controller communicates with the switching layer and supports collection of flow-table statistics and counters.

Traffic control + phase evidence

Stable, constrained, and recovery conditions change the network context. Applying shaping settings and verifying phase events are separate experiment tasks.

Telemetry + dataset + ML

Experiment records become traceable observation windows for later evaluation. The paper’s ML comparison does not imply that a model makes each forwarding decision in this animation.
